Weekly MCP Roundup: New MCP Servers Worth Watching (Sep 6, 2026)

By HermesBee Team · Developer Tools · September 6, 2026 · 6 min read

If last week's MCP story was about specialized workflows, this week's is about trust. The fastest-rising project in our scans doesn't give agents a new capability — it checks their work. Alongside it: a theorem-graph server for math papers, travel data done right, and WordPress officially entering the MCP world. Based on our daily GitHub, Hacker News and Product Hunt scans, here is what deserves your attention this week — and the gaps still open for builders.

This week's MCP servers worth watching

  • reverify (~920★): the standout of the week, and of our last two scans. Its premise: when an LLM claims something about a binary — a DLL, a driver, a system file — a deterministic tool adjudicates instead of trusting the model. In its published benchmark, AI answers about Windows system binaries were wrong on the vast majority of files, and the tool caught every one. Anti-hallucination infrastructure shipping as pip + CLI + MCP is exactly the shape serious teams want.
  • papergraph-mcp (76★): turns arXiv and LaTeX math papers into theorem dependency graphs an agent can walk — "what does this proof build on?" Small stars, big idea. It rides the same wave as local academic search; our own LitSearch serves the retrieval side of the same need.
  • china-travel-kit (124★): inbound-travel data delivered as a source-aware CLI + API + MCP. Worth studying less for the topic than for the packaging — one dataset, three doors, each agent platform served natively.
  • IDA-instances-MCP (111★) and jmeter-mcp (64★): reverse engineering and load testing join the agent stack. Following x64dbg MCP from two weeks ago, security and QA tooling are now reliably MCP-first.
  • shim-mcp (47★): small, but historically interesting — it put a WordPress MCP into the official plugin directory. CMS platforms are officially MCP-aware now. Meanwhile TrackMCP (a Product Hunt launch) tracks MCP servers themselves: discovery and monitoring have become their own niche.
  • Also this week: lemmalog, the auditable-memory engine we covered at 127★ last week, doubled to ~283★ — trust in memory is sticking. And Anthropic's official commerce-agents blueprint (~2,037★) shows staged, human-confirmed write operations becoming the reference pattern for commercial agents.

The pattern: from capability to accountability

Read together, this week's releases describe an ecosystem adding a verification layer. reverify checks binary claims with deterministic tools; lemmalog makes every remembered fact auditable; commerce-agents puts a human in the purchase loop. This mirrors developer anxiety on Hacker News — "Did Claude increase bugs in rsync?" drew over 300 points this week. Agents that propose and tools that adjudicate is becoming the default architecture, not a paranoia option.

Two quieter trends: first, multi-form distribution is now standard — reverify ships pip+CLI+MCP, china-travel-kit ships CLI+API+MCP, and this week's breakout local-WeChat intelligence tool (362★) ships a read-only CLI plus an agent skill. Ship every door an agent might enter through. Second, discovery is saturating: mcpservers.org now lists 9,800+ servers. Being in a directory is table stakes; narrow vertical positioning is what actually gets found.

Supply gaps agent builders can still claim

  • SEO / keyword-data MCP. A local-first keyword research tool hit 200★ this week — in desktop form only. Demand is validated; no dominant MCP server serves it yet. Keyword and rank data wrapped as MCP is still an open niche.
  • CMS governance MCP. WordPress is officially MCP-aware as of this week, but audit, staging and publish-approval workflows barely exist. Anyone building "agent edits your site, safely" has a first-mover window.
  • Source-code verification MCP. Binaries are now covered (reverify). The equivalent layer for source code — deterministically checking what a code-gen agent claims — is still unclaimed, and the rsync thread shows the anxiety is real.

HermesBee's take

This week validated the three bets we made at launch: winning MCP tools are local-first, buy-once, and specialized. Our line — Unified Scraper MCP, CF Bypass Browser MCP, LLM Scraper MCP and the rest of the product line — runs locally with no API key and no subscription. The takeaway from this week: prefer components that can prove themselves — verification servers, auditable memory, deterministic adjudication — and treat "trust me" as a red flag in anything wired into your agent.
