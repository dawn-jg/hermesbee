## Quick Start / 快速开始

### ScrapeBox

```bash
# 1. Download & unzip / 下载解压
# 2. Install: setup.bat (Win) / bash setup.sh (Mac/Linux)
# 3. Start: start.bat / bash start.sh
# 4. Use / 使用
curl "http://localhost:8080/text?url=https://example.com"
```

### MCP Servers

Add to your Claude Desktop / Cline / Cursor config / 配置到你的 AI 客户端：

```json
{
  "mcpServers": {
    "cf-bypass-browser": {
      "command": "python3",
      "args": ["path/to/cf_bypass_browser.py"]
    }
  }
}
```

### Desktop Tools / 桌面工具

Double-click start.bat, browser opens automatically / 双击 start.bat，浏览器自动打开。
