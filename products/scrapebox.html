ScrapeBox is a local HTTP scraping service that runs entirely on your machine. Start it once, then call it from any script, tool, or browser to fetch and extract web content — no cloud, no API keys, no subscription.

Features

  • Extract HTML / text / links / tables from any page
  • Bypasses low/medium anti-bot protection automatically

  • Works on Windows / macOS / Linux
  • Zero cloud dependency, works even offline (after setup)

Quick Start

  1. 1. Run setup.bat (Win) or bash setup.sh (Mac/Linux) to install
  2. 2. Double-click start.bat to launch the service
  3. 3. Open a browser or terminal:
  4. curl "http://localhost:8080/status"
  5. curl "http://localhost:8080/text?url=https://example.com"
