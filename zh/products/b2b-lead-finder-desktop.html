桌面 B2B 找线索。公司、邮箱、LinkedIn 职位、GitHub 开发者。无需登录。

免编程的桌面 B2B 找线索工具。双击启动，浏览器自动打开。搜索公司、生成决策人邮箱、抓取联系页、扫描 LinkedIn 职位、搜索 GitHub 开发者、导出 CSV。中英双语界面。

功能

  • 搜索公司——获取官网和公开信息
  • 生成决策人候选邮箱（7 种格式）
  • 抓取联系页提取邮箱和电话
  • LinkedIn 职位扫描（免登录，招聘信号）
  • 邮箱验证（MX 记录 + SMTP 握手 + catch-all 检测）
  • GitHub 开发者搜索（技术决策者）

快速开始

  1. 1. 双击 setup.bat（Win）或 bash setup.sh（Mac/Linux）
  2. 2. 双击 start.bat——浏览器自动打开
  3. 3. 标签1：输入公司名 → 搜索公司信息
  4. 4. 标签2：输入名字+域名 → 生成候选邮箱 → 导出 CSV
  5. 5. 标签3：粘贴联系页 URL → 抓取邮箱和电话
