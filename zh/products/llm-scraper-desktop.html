人人可用的 AI 网页提取。中英双语界面。

非程序员最轻松的 AI 网页数据提取方式。输入网址，用中文或英文描述要什么数据，就能拿到可导出 CSV 的结构化结果。首次运行有引导配置页，只需填一次 LLM API Key。

功能

  • 无需编程——描述即可提取
  • 中英双语界面（默认英文）
  • 首次运行引导配置（Key 保存在本地）
  • 支持 DeepSeek / OpenAI / Kimi Key
  • 导出 JSON 或 CSV
  • 自动绕过反爬保护

快速开始

  1. 1. 双击 setup.bat（Win）或 bash setup.sh（Mac/Linux）
  2. 2. 双击 start.bat——浏览器自动打开
  3. 3. 首次运行：配置页 → 选服务商（DeepSeek ★）→ 粘贴 API Key → 保存
  4. 4. 输入网址，描述要提取什么（如"提取所有产品价格"）
  5. 5. 点击提取数据 → 查看 JSON → 导出 CSV
