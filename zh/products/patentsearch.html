PatentSearch

一次性买断 · 本地运行
$24.9 买断制，终身使用

一个应用搜索两大免费官方专利库（欧洲专利局 Espacenet + 美国专利局 USPTO）。

在一个界面搜索超过 2 亿件专利——来自两大免费官方数据库：Espacenet（欧洲专利局）和 USPTO ODP（美国专利商标局）。结果展示专利号、标题、日期和申请人。点击任意结果查看详情和原始专利页面。免费 API Key 应用内引导注册，无需昂贵的商业专利工具。

功能

  • Espacenet OPS + USPTO ODP 双库检索
  • 专利号 / 标题 / 日期 / 申请人
  • 专利详情 + 原文页面链接
  • 结果导出 CSV
  • 应用内引导注册免费 API Key
  • 中英双语界面

快速开始

  1. 在 Gumroad 购买并下载压缩包
  2. 解压后双击 PatentSearch 启动
  3. 打开设置，免费注册 Key（Espacenet / USPTO），填入并测试
  4. 搜索专利并导出 CSV

适合人群: 工程师、专利检索人员、研发团队、初创企业
