ScrapeBox

一次性买断 · 本地运行
$29 买断制，终身使用

本地 REST 爬虫 API。双击启动，curl 调用。

ScrapeBox 是在你自己电脑上运行的 HTTP 爬虫服务。启动一次，之后任何脚本、工具或浏览器都能调用它抓取和提取网页内容——无需云端、无需 API Key、无订阅。

功能

  • 提取任意网页的 HTML / 文本 / 链接 / 表格
  • 自动绕过低/中等级反爬保护
  • 100% 本地运行——数据不出本机
  • 支持 Windows / macOS / Linux
  • 零云端依赖，安装后可离线使用
  • 无订阅、无月费，永久使用

快速开始

  1. 1. 运行 setup.bat（Windows）或 bash setup.sh（Mac/Linux）安装
  2. 2. 双击 start.bat 启动服务
  3. 3. 打开浏览器或终端调用：
  4. curl "http://localhost:8080/status"
  5. curl "http://localhost:8080/text?url=https://example.com"
