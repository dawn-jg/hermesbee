MCP 生态周报：9700 万次月下载与不足 5% 变现——配置审计、分发现实与本地优先（2026年9月27日）

作者 HermesBee Team · 开发者工具 · 2026年9月27日 · 6 分钟阅读

本周 MCP 生态终于有了自己的成绩单，难看得很有价值。协议用量早已进入主流：SDK 月下载约 9700 万次（2024 年底还是 10 万量级），公共活跃服务器超过 1 万个，GitHub 上打 mcp-server 标签的仓库超过 15900 个。但多份独立分析对变现侧的结论一致：有收入的服务器不足 5%。同时，本周真正有分量的技术新闻不是新服务器，而是审计与收容——配置扫描工具、零信任网关，以及一组"朴素注入过滤到底有多不灵"的硬数据。

供给侧的真实数字

指标数值

把这几行放在一起，结论不用猜：瓶颈已从"做出来"移到"被看见"。社区口径的量化结果是——在 5 家以上目录（npm、Glama、PulseMCP、mcp.so、Smithery、官方 Registry）上架的服务器，安装量大约是只发一次的 10 倍。如果你手上已经有一个能跑的服务器，本周回报最高的一小时不是加功能，而是把上架清单一次性铺完。

审计潮：配置扫描器能扫出什么

本周最锋利的新工具是 mcp-audit-tool（MIT，约 68★）：静态扫描 Claude Desktop、Cursor、Windsurf、Cline、Zed、VS Code 的 MCP 配置文件，内置 12 条规则对齐 OWASP MCP Top 10，输出 0–100 分 + A+→F 等级，并能吐 JSON/SARIF 直接进 CI。我们拿一份"故意做坏"的三服务器配置去跑，结果是 0/100 分、F 级、6 条发现（2 条 CRITICAL、3 条 HIGH、1 条 MEDIUM）——工具有效，而它抓到的问题几乎全是"修起来很简单、靠眼睛发现不了"。在让 Agent 真正调用工具前，至少过这五项：

  • 配置文件里的硬编码密钥——会被提交或被同步带走。
  • 未锁版本的 npx -y 安装——典型的 rug pull 入口。
  • 文件系统根目录授权——只需要一个目录却拿到盘符根。
  • 会"指挥"Agent 的工具描述（工具投毒）。
  • 没有认证的远端端点——不是功能，是敞开的门。

工具投毒不是正则能解决的问题

一组新的公开测试集给出了不太好听的数据：在 629 条真实 AgentDojo 注入攻击（嵌在工具输出里）上，正则拦截率 0%，Meta 的 Prompt Guard 2 只拦下约 1%。也就是说，"用关键词匹配过滤抓来的网页文本"这条路一上来就输了。真正对得上威胁的是结构性手段——最小权限的工具面、默认只读、破坏性调用人工确认、在边界处收容。这正是新一代零信任 MCP 网关（如 Rust 写的 MCPBastion）的用途：收窄每个服务器的能力范围、进出双向脱敏、按工具限速与限额，被劫持的 Agent 就没法批量外带数据。装之前静态扫配置、装之后运行时过网关，两半才算盖住；设计侧原则见我们的 MCP 服务器安全指南。

本地优先已经从"偏好"变成"立场"

三条互相独立的信号指向同一结论。"在你自己账号里跑、替代 SaaS"的开源应用清单破千星，把自托管从论点变成目录级运动。技术叙述也硬了：本地优先主张"数据与处理的主副本就在你手上的设备里，服务器是可选项"，在隐私、成本、寿命、能力四项上同时获益。产品实物也在持续出现——一位独立开发者上线 $49 一次性买断的完全离线桌面应用（Electron + SQLite），首周 1200 名用户，不订阅、不融资，形态和我们自己的产品线一致。一条必须正视：因为"终身授权"被虚报收入的人污染了，老实做买断的人现在得主动出示可验证凭据才有人信。

协议提示与剩下的供给空位

2026 年 7 月版规范把协议转为无状态（会话被请求头取代），OAuth 走 RFC 9207 大改，并让 MCP Apps（服务器自带 UI）成为一等公民。无状态对轻量自托管服务器是利好；MCP Apps 才是战略变量——自带 UI 的服务器开始和成品桌面软件重叠。仍空着的几个位置：

  • 安全与合规工具——企业把头号担忧定为 MCP 投毒，而最好的审计工具还不到 100 星。
  • CI/CD 与测试基建——几乎没人做"跑测试、读失败日志、提修复 PR"。
  • 无需登录的 B2B 数据源——头部全是 OAuth 门控，与已有的线索挖掘工具天然衔接。
  • Agent 成本治理——没人暴露"按工具、按调用"的成本归属。

我们如何评估 MCP 服务器

标准没变，而且本周把它钉得更实：能不能搞定最难的 30%——反爬墙与动态页（见 Cloudflare 绕过指南）？是否本地运行、一次性买断而不是每次调用计费？返回结构化数据还是原始 HTML——原始 HTML 是每次调用都要付的"上下文税"（见 MCP 抓取服务器指南）？以及在碰你的数据之前能不能过一遍安全审查？上一期见 9 月 20 日 MCP 周报。

HermesBee 的判断

2026 年 9 月，这个生态的真问题不是供给，而是信任与分发。9700 万次月下载、二十个服务器里不足一个赚到钱——这描述的正是"可发现性"与"可验证性"成为稀缺品的市场。所以我们把产品线钉在本地、买断、可审计三件事上：Unified Scraper MCP、CF Bypass Browser MCP、LLM Scraper MCP 及全部产品列表，都跑在你自己机器上——无账号、无云依赖、无按次计费。当审计工具告诉你"锁版本、把数据留在本地"时，那正是我们从第一天交付的架构。

总结

本周 MCP：SDK 月下载约 9700 万，而不足 5% 的服务器有收入——分发比再加一个功能更值钱；配置扫描工具落地，我们那份故意做坏的配置拿到"名正言顺"的 0/100 分；629 条注入实测显示正则拦截率为 0%；本地优先以目录运动形态破千星；7 月版规范走向无状态，并让"服务器自带 UI"成为一等公民。我们每周发布一篇这样的周报。
