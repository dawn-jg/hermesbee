专利搜索工具对比：Espacenet、USPTO、Google Patents 与桌面替代方案

By HermesBee Team · Developer Tools · 2026年8月10日 · 7 分钟

专利研究曾经意味着昂贵的数据库（LexisNexis、Derwent）或痛苦的浏览器操作。2026 年，免费的官方 API 改变了游戏规则——建立在它们之上的桌面工具正在取代两者。

免费官方 API

  • Espacenet OPS（EPO）——开放专利服务 API。免费层每月约几千次请求。覆盖欧洲专利局的世界专利数据。
  • USPTO ODP——开放数据门户，旧 API 的继任者。免费 API Key，美国专利全文数据。
  • Google Patents——没有官方 API，但搜索 UI 出色，全文覆盖完整。

对比表

工具覆盖API监控成本
Espacenet 网页全球OPS（免费层）无免费
USPTO 网页仅美国ODP（免费 Key）无免费
Google Patents全球无官方无免费
PatentSearch（桌面）Espacenet + USPTO 合并OPS + ODP无$24.9 买断
PatentWatch（桌面）Espacenet + USPTOOPS + ODP有（自动提醒）$39.9 买断

为什么桌面优于浏览器

专利分析师和追踪竞品的创始人每天都面对同样的流程：搜索、阅读、导出、下周再查。浏览器很痛苦（无导出、无持久化、手动重复搜索）。桌面工具持久化历史、导出 CSV，而且——关键的是——监控：PatentWatch 按计划自动重查，当竞品提交新专利时提醒你，使用同样的免费官方 API，一次买断。

什么时候值得付费

如果你偶尔搜索专利，免费网页工具就够了。如果你每周追踪竞品（创业公司、IP 团队、专利律师），监控工作流很快回本。桌面买断模式对个人运营和小团队优于订阅数据库。

总结

免费官方 API（Espacenet OPS + USPTO ODP）现在为现代专利工具提供动力。基于它们的桌面应用把免费数据与持久化、导出和监控结合起来——这是浏览器研究缺失的部分。
