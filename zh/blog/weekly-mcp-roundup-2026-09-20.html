MCP 生态周报：记忆层、Agent 公司制与每步成本之战（2026年9月20日）

作者 HermesBee Team · 开发者工具 · 2026年9月20日 · 6 分钟阅读

本周我们每天对 GitHub、Hacker News 和 Agent 生态的扫描浮出两条主线。第一条：记忆与 Agent 基建层正在独立成类——一个 Markdown 原生的长期记忆 runtime 一个月冲到近千星，一个把团队架构映射成 MCP 角色的"Agent 公司"框架破 1600 星。第二条：一场彻底的上下文成本运动——我们的扫描一周内发现至少五个 Jev 风格复刻项目，攻的是同一个问题：Agent 每一步决策太贵。对在 MCP 上做构建的人来说，本周值得看的项目和还没人占的空白如下。

本周值得关注的新 MCP

  • agent-memory（约 955★）：面向 Agent 的长期记忆 runtime，一个月近千星。Markdown 原生、本地优先、以检索为中心——记忆层正式独立成产品品类。这个需求我们感同身受：自己的 Agent 往往任务还没做完，上下文先被撑爆。
  • headcount（约 1627★）：把多个 Agent 组织成一家公司——CEO、部门、按角色分工委派——全部通过 MCP 风格的工具调用协调。Agent 编排正从"一个 Agent 带一堆工具"走向"一群 Agent 带组织架构"。做多 Agent 工作流的都该看一眼。
  • reverify（约 1229★）：两周前我们报道时的防幻觉校验层（约 920★）继续上涨，验证了上期"问责"主题。它给 MCP 开发者的启示：附着在 Agent 断言上的确定性检查是能卖钱的产品，不是锦上添花。
  • fast-jev-compaction（约 4070★，一天前还是 2964★）：本周爆款。它替换编码 Agent 默认的上下文压缩流程，砍长会话的 token 消耗。它本身不是 MCP 服务器——但它打中的成本问题，MCP 服务器下一个就会感受到。
  • jev-ultrafast（约 7900★）：browser-use 官方二代超快浏览器 Agent，本周中还是约 5200★。两次决策架构，每步动作 token 极省。加上 SemIf（约 1864★，冻结 4B 开源模型单张 3090 可跑）和 typesafe-computer-use（约 472★，桌面操控每步约 $0.0002），指向异常一致：生态正从"更大的模型"转向"更小的决策"。
  • 同周动态：open-seo-mcp-skills（约 1066★）证明开源 SEO/GEO 审计有真实需求；okf-agent-memory（约 697★）把 Git 原生持久化带进 Agent 记忆；一个面向 Digikala 的区域电商 MCP（两周 86★）则说明垂类数据服务器依旧是从零到起量最快的路。

大趋势：Agent 想得更小，记得更久

把本周的上涨项目摆在一起，一个论点浮出水面：Agent 单步的边际成本已经是新瓶颈。fast-jev-compaction 压缩历史，jev-ultrafast 和 SemIf 把每次决策缩到小模型，agent-memory 干脆把状态搬出上下文窗口。对 MCP 开发者这条结论很直接——一个返回 50KB 原始 HTML 的服务器，等于每次调用都征一道沉重的"上下文税"。要么返回结构，要么别返回。我们的提取工具（见 MCP 抓取服务器指南）坚持结构化输出优先，就是这个原则。

第二条线是带出处的记忆。从 agent-memory（约 955★）到 okf-agent-memory（约 697★）再到上周的可审计记忆引擎，市场正在收敛到本地、可检查的存储——和 local-first MCP 走红是同一种本能："数据不出本机"。把记忆放在云端的工具，正开始从卖点变成负债。

开发者还能切入的供给空白

  • 可观测 MCP：本地编码 Agent 可观测工具本月冲到约 683★，但几乎没有 MCP 服务器对外暴露 Agent 运行指标。"我的 Agent 今天到底干了啥"服务器，仍是空位。
  • 垂类电商 MCP：Digikala 服务器两周 86★ 说明区域垂类变现快。中国垂类——二手平台、同城服务、短视频电商——还没人占。
  • 成本治理 MCP：人人都在做上下文压缩，几乎没人暴露按工具、按调用的成本账本。一个预算感知的 MCP 网关——配额、花费追踪、廉价模型路由——还没有强势玩家。

我们如何评估 MCP 服务器

推荐任何 MCP 服务器之前，我们只问三个问题：能否搞定最难的 30%——反爬墙和动态页（方法见 Cloudflare 绕过指南）；是否本地运行、一次性买断而非按次计费；返回的是结构化数据还是原始 HTML——因为原始 HTML 是你每次调用都要付的上下文成本。凡是要碰你数据的组件，先过一遍安全审查——见 MCP 服务器安全指南。

HermesBee 的判断

本周再次验证了我们反复下的三个判断：能赢的 MCP 工具本地优先、一次性买断、垂直专精。我们的产品线——Unified Scraper MCP、CF Bypass Browser MCP、LLM Scraper MCP 及全部产品列表——本地运行，无 API Key、无订阅，并且正因为"上下文是 Agent 支付的货币"才坚持结构化输出。当生态把每步决策优化到 $0.0002 级，喂给这些决策的工具也必须更精瘦。上一期见 9 月 6 日 MCP 周报。

总结

本周 MCP 生态：记忆层独立成品类，Agent 组织架构走向主流，五项目复刻潮宣告单步决策成本成为新瓶颈。校验工具持续上涨，垂类数据服务器持续跑赢，而可观测、垂类电商、成本治理三个空白仍待认领。我们每周发布一篇这样的周报。
