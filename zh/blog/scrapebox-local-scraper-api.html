ScrapeBox：本地爬虫 API，双击启动

痛点

你写了个 Python 爬虫脚本，但遇到这些问题：

  • 网站有反爬虫，返回空数据
  • 每次要手动启动 Selenium/Playwright
  • 云爬虫 API 太贵，每个月交月费

解决方案：ScrapeBox

ScrapeBox 是一个在本地运行的 REST 爬虫 API。下载解压，双击 start.bat，就能用 curl 调用。

curl "http://localhost:8080/text?url=https://example.com"

核心功能

接口说明
/scrape?url=...返回完整 HTML
/text?url=...提取纯文本
/links?url=...提取所有链接
/tables?url=...提取表格数据

为什么选 ScrapeBox？

  • 一次性买断 — $29，不是月费
  • 本地运行 — 数据不出你的电脑
  • 绕过反爬 — 内置隐身浏览引擎
  • 零配置 — setup.bat + start.bat 搞定

对比

方案费用数据隐私部署难度
ScrapeBox$29 一次性✅ 在本地✅ 双击启动
云 API$9-99/月❌ 第三方服务器✅ HTTP 调用
自己写 Playwright免费✅ 在本地❌ 要写代码调试
