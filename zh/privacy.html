隐私政策

最后更新：2026 年 8 月

HermesBee 坚持隐私优先设计。本政策说明我们的软件和网站如何处理你的数据。

1. 本地优先软件

我们的桌面工具和 MCP 服务器在你本机运行。你的文档、论文、笔记和搜索数据不会离开你的电脑——无云存储、无遥测、无追踪。

2. 自带 API Key（BYOK）

使用 AI 的产品让你自备 API Key。你的 Key 只保存在你的设备上，仅用于调用你选择的 API 服务（如 OpenAI、DeepSeek）。我们从不查看、存储或传输你的 Key。

3. 支付

所有购买由 Gumroad 处理。我们不收集或存储任何支付卡信息。支付数据处理请参阅 Gumroad 的隐私政策。

4. 网站

本网站由 Cloudflare Pages 托管的静态页面，不使用分析 Cookie 或收集个人数据。

5. 联系

对本政策有疑问？发邮件至 860087395@qq.com。
